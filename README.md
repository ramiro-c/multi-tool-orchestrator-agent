# multi-tool-orchestrator-agent

Orquestador con registro dinámico de tools, enrutado por capacidades,
permisos acotados, ejecución en paralelo y resolución de conflictos.

**Qué demuestra:** orquestación segura y escalable de múltiples tools.

## Checklist de features clave

- [ ] Registro dinámico de herramientas (tool registry)
- [ ] Routing basado en capacidades declaradas
- [ ] Scope de permisos por tool/sesión
- [ ] Ejecución en paralelo cuando sea seguro
- [ ] Resolución de conflictos entre resultados de tools
